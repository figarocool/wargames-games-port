# Wargames Games Port

Ricostruzione nativa in C del gioco, con codice, documentazione e strumenti di confronto nella cartella `rebuild/`.

Il repository non distribuisce l'eseguibile originale né i suoi asset. Per eseguire la ricostruzione sono necessari i file originali nelle cartelle `Gfx/`, `Snd/`, `Vid/` e `Wopr/`, che devono trovarsi accanto a `rebuild/`.

Per requisiti, compilazione, test e stato della ricostruzione, consulta [`rebuild/README.md`](rebuild/README.md).
